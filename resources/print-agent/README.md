# Онлайн принтер Wesetup

Программа для компьютера, к которому подключён принтер. Позволяет
отправить любой журнал на печать с телефона — из любого раздела
wesetup.ru, кнопкой «На принтер заведения».

Пришла внезапная проверка — журнал печатается за один тап, никого не надо
звать к компьютеру.

## Установка

1. Скачать архив в Wesetup: **Настройки → Онлайн принтер → Скачать программу**.
2. Распаковать в любую папку на компьютере с принтером.
3. Запустить **`Установить.bat`**.

Всё. Программа спросит почту и пароль от Wesetup, предложит выбрать
принтер из списка и пропишет себя в автозапуск. Node.js, если его нет,
скачается сам.

## Что нужно знать

**Пароль спрашивается один раз** и на диск не записывается. Сервер в
обмен выдаёт ключ доступа, и дальше программа работает по нему — поэтому
после перезагрузки она поднимается сама и ничего не спрашивает.

Ключ лежит в `config.json`. Если машину списали или ключ утёк — отключите
её в Wesetup: **Настройки → Онлайн принтер → Отключить**. Ключ сразу
перестанет работать.

**Автовход в Windows** нужно включить отдельно: `Win+R` → `netplwiz` →
снять галочку «Требовать ввод имени и пароля». Без этого после
перезагрузки никто не войдёт в систему и печатать будет некому. Программа
об этом предупредит, но включить за вас не может — это решение про
безопасность машины.

**SumatraPDF не обязательна.** Без неё печать идёт средствами Windows.
Если положить `SumatraPDF.exe` (portable) рядом с программой, печать
станет тихой — без мелькающих окон. Программа сама выберет, чем печатать.

## Как это работает

Раз в 5 секунд программа спрашивает сервер, есть ли что напечатать.
Опрос, а не входящее соединение: компьютер стоит в заведении за роутером,
снаружи до него не достучаться.

```
GET  /api/print/agent/poll          → { job: { id, docTitle, pdfUrl } } | { job: null }
GET  /api/print/jobs/<id>/pdf       → готовый бланк
POST /api/print/jobs/<id>/complete  → напечатано
POST /api/print/jobs/<id>/fail      → не вышло, с причиной
POST /api/print/agent/state         → какой принтер выбран
```

Ключ передаётся заголовком `Authorization: Bearer`, а не в адресе
запроса: адреса целиком попадают в логи веб-сервера.

Нет связи — задания копятся на сервере и печатаются, когда компьютер
вернётся. Задание, зависшее дольше 10 минут (выключили машину посреди
печати), сервер сам возвращает в очередь; после трёх неудачных попыток
помечает ошибкой, чтобы сломанный принтер не держал собой всю очередь.
Задание, провисевшее сутки, отменяется: печатать журнал суточной давности
при проверке хуже, чем не печатать вовсе.

## Файлы

| Файл | Что делает |
|---|---|
| `Установить.bat` | всё сразу: Node, вход, принтер, автозапуск |
| `setup.js` | вход в Wesetup и выбор принтера |
| `agent.js` | опрос сервера, скачивание бланка, печать |
| `uninstall.bat` | снять автозапуск |
| `config.json` | адрес, ключ доступа, принтер (создаётся при установке) |
| `logs/agent.log` | лог с ротацией по 10 МБ |

## Для разработчика

Исходники живут в репозитории Wesetup (`resources/print-agent/`) и
отдаются архивом на лету через `/api/print/agent/download`. Так архив не
может отстать от кода и его не надо руками класть на каждый сервер.
Зависимостей у программы нет — только стандартная библиотека Node.

Каркас взят у агента печати Magday (`C:\www\managermagday\print-agent`).
Убрано: puppeteer (бланк собирает сервер Wesetup) и хранение содержимого
файла в очереди — у Magday base64 чека лежит прямо в строке таблицы, для
журнала за месяц это сотни килобайт на задание.
