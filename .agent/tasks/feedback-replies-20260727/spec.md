# Ответы на обращения из ROOT

## Scope

Добавить ROOT-пользователю возможность ответить на запись обратной связи в
`/root/feedback`. Ответ сохраняется у обращения и создаёт in-app уведомление
автору обращения.

## Acceptance criteria

- **AC1:** ROOT может открыть форму ответа у обращения, написать непустой ответ
  и отправить его.
- **AC2:** Ответ и время ответа сохраняются и отображаются в карточке обращения
  после обновления страницы.
- **AC3:** Если у обращения сохранён `userId`, отправка ответа создаёт для этого
  пользователя новое непрочитанное in-app уведомление с текстом ответа.
- **AC4:** API ответа доступен только ROOT; не-ROOT не может создать ответ или
  уведомление через этот endpoint.
- **AC5:** Если автор обращения не определён, ответ сохраняется, а UI честно
  сообщает, что in-app уведомление не было отправлено.

## Out of scope

- Email, Telegram и SMS-ответы.
- Двусторонний чат и несколько ответов на одно обращение.
