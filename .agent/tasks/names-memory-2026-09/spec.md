# names-memory-2026-09 — Память наименований + окно бракеража на телефоне

Заморожено: 2026-09-19.

## Задача (владелец, 2026-09-19, скриншоты окна «Добавление новой строки» бракеража с iPhone)

1. Наименования, которые вводили раньше, сохраняются и предлагаются в
   выпадающем списке — последние введённые сверху; по всей организации,
   чтобы и в других журналах был выпадающий список, где уместно.
2. На телефоне поля заходят друг на друга (дата и время в одной строке).
3. Кнопки «Да/Нет» («Разрешение к реализации»): непонятно, какая нажата.
4. Оценка по умолчанию — «Отлично».
5. Окно «слайдится вбок» (горизонтальный скролл).
6. Mini App — то же самое.

## Решение

- Таблица `NameSuggestion (organizationId, scope, value, useCount, lastUsedAt)`,
  scope `dish` (бракераж готовой продукции, интенсивное охлаждение) и
  `product` (входной контроль/приёмка, скоропорт). `GET/POST /api/name-suggestions`.
  Хук `useNameSuggestions(scope)` → `options(catalog)` (недавние сверху +
  справочник документа) и `remember(values)` после сохранения строки.
- Бракераж: `DateTimePair` с `min-w-0`, контейнер `overflow-x-hidden`;
  «Да/Нет» — выбранный с заливкой, галочкой и кольцом, невыбранный белый;
  `organoleptic` по умолчанию «Отлично».
- Скоропорт: поле наименования — `SuggestInput` вместо «список + или введите
  новое»; «Соответствует / Не соответствует» — тот же стиль выбранного.
- Интенсивное охлаждение: `SuggestInput` вместо `datalist`.
- Входной контроль: список продукции в окне строки — недавние сверху.
- Mini App рендерит те же клиенты.

## Acceptance criteria

- AC1 Сохранение строки бракеража с новым наименованием → `GET /api/name-suggestions?scope=dish`
  возвращает его первым; в другом документе бракеража и в окне интенсивного
  охлаждения оно в списке первым.
- AC2 Сохранение строки скоропорта → значение первым в `scope=product`; в окне
  входного контроля оно первым в списке продукции.
- AC3 На 390px в окне бракеража поля даты и времени не пересекаются
  (правый край даты ≤ левого края времени), `scrollWidth` контейнера формы
  равен `clientWidth`.
- AC4 «Да» по умолчанию помечено галочкой и `aria-checked=true`, «Нет» —
  белое; клик по «Нет» переключает.
- AC5 Новая строка бракеража открывается с оценкой «Отлично».
- AC6 `/mini/documents/<id>` бракеража — те же элементы.
- AC7 Unit-тесты `name-suggestions.test.ts`, `npm run typecheck`, eslint — чисто.
