## По критериям

- **AC1** — реестр колонок обоих журналов, приоритет `config.columns` → общий набор организации → флаги → реестр,
  обязательные колонки не скрываются, подписи ≤ 60 (юнит-тесты).
- **AC2** — документ без набора выглядит как раньше (флаги по умолчанию); нормализаторы сохраняют `columns` и
  синхронизируют `showX`; PDF берёт подписи и видимость из набора (e2e: «Блюдо» и «Продукт» в PDF, скрытых колонок нет).
- **AC3** — «Настройки журнала → Колонки таблицы»: обязательная колонка с неактивным переключателем, показ, переименование;
  меню заголовка по правому клику: «Скрыть колонку», «Переименовать»; данные скрытой колонки сохраняются.
- **AC4** — «Применить ко всем документам» → подтверждение с выбором объёма → `PUT /api/settings/journal-columns/[code]`:
  тост «Обновлено: N документов», второй документ получил набор, набор стал общим, новый документ получает его;
  повар → 403, журнал без реестра → 404.
- **AC5** — таблица, диалог строки (в том числе из карточки на телефоне) и PDF показывают один набор; скоропорт — ячейки
  строки совпадают с колонками; запись адаптера TasksFlow сохраняет набор.
- **AC6** — typecheck, lint, юнит и e2e локально; test:gate — хуками коммита и пуша; прод — только чтение после деплоя.
