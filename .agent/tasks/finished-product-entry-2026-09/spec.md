# finished-product-entry-2026-09 — бракераж готовой продукции: ввод записей

Источник: обращение заказчика («Одинцовская Лингвистическая Гимназия»), 2026-09-17. Заморожено 2026-09-17.

## Проблема
1. «Добавить списком» создавало строки только с наименованиями и текущим временем, без окна с полями, как у
   «Добавить изделие».
2. В таблице ячейки «Отв. исполнитель» и «ФИО лица, проводившего бракераж» «не редактировались»: ячейка со
   справочником при фокусе подменялась на `<input list>`, на iPhone/iPad подмена теряла фокус.
3. Органолептическая оценка — свободный текст, заказчик просит выпадающий список.

## Acceptance criteria
- **AC1** «Добавить списком»: окно с полем списка наименований и теми же полями, что у одной записи (даты, оценка,
  температура и т. д., разрешение, ответственный, проводивший бракераж); значения общие для всех строк списка, у
  каждой строки свой id (e2e).
- **AC2** `JournalCellInput` с `list`: без подмены элемента; подсказки из `<datalist>` показываются списком под
  ячейкой (мышь и тач), выбор подставляет значение через `input`-событие, ввод вручную сохраняется; клавиатура:
  стрелки, Enter, Esc (e2e: десктоп и телефон с тачем).
- **AC3** Органолептическая оценка: в окне записи — Select «Отлично / Хорошо / Удовлетворительно /
  Неудовлетворительно / Своя формулировка…»; в ячейке таблицы — подсказки с теми же значениями (e2e).
- **AC4** «Что нового»: категория «Бракераж готовой продукции».
- **AC5** typecheck, lint, e2e локально (`e2e/finished-entry.ts`), регрессия `journal-columns-2026-09/e2e/columns.ts`;
  прод — смоук после деплоя.

## Ограничения
- Общий компонент ячейки используется в 6 клиентах журналов: поведение без справочника не меняется.
- e2e только на `wesetup_e2e` (localhost:5432).
