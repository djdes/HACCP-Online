# profile-nudge-compact-2026-09 — компактная анкета после регистрации + автопароль

Заморожено: 2026-09-05 по скриншотам владельца (iPhone, Safari): анкета
«Аккаунт создан!» не помещалась в экран, поля шли столбиком.

## Задача (владелец)

1. «Оформить меня сотрудником» — компактнее, меньше текста, в одну строку.
2. Сфера, тип, точек — в одну строку (допустимо), остальные поля тоже
   парами по смыслу. На первом экране телефона должно быть видно всё.
3. Новый пароль генерируется сам: 6 знаков, буквы обоих регистров, цифры и
   один простой спецсимвол; сбоку кнопка перегенерации. Человек может
   сменить его вручную здесь или в личном кабинете.

## Acceptance criteria

- AC1 На 390×758 (видимая область iPhone Safari) форма анкеты не скроллится:
  `form.scrollHeight <= form.clientHeight`; на 390×844 и 1280×900 тоже.
- AC2 Галочка «Я сотрудник» и поле «Должность» в одной строке; без галочки
  поле должности скрыто.
- AC3 Поля стоят парами: Сфера · Тип, Точек · ИНН, Ваше имя · Пароль;
  телефон с однострочным промо TasksFlow; кнопки «Готово» и «Показать демо»
  в один ряд.
- AC4 Поле «Пароль для входа» предзаполнено паролем из 6 знаков
  (заглавная, строчная, цифра, ровно один символ из `!?#*+=@`, без 0/O/1/l/I),
  кнопка рядом подбирает другой, можно ввести свой (от 6 знаков).
- AC5 При сохранении с паролем API шлёт письмо «Новый пароль для входа»
  (`sendPasswordChangedEmail`), пароль из письма о регистрации заменяется.
- AC6 `npm run typecheck`, eslint затронутых файлов, `npm test` — зелёные;
  новые тесты генератора проходят.
