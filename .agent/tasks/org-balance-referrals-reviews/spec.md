# Баланс баллов организации, рекомендации друзьям и отзывы за баллы

TASK_ID: org-balance-referrals-reviews
Статус: FROZEN (2026-09-03)

## Цель

Единая система «баллы организации» (1 балл = 1 ₽), два источника пополнения
(рефералы и отзывы), одна точка списания (оплата подписки), прозрачная
история для клиента и ROOT.

Полное ТЗ — в исходном md-задании. Ключевые решения (1–11) и модель данных
приняты без изменений.

## Acceptance criteria

- **AC1 Леджер.** Два параллельных списания не сводят `balanceRub` в минус;
  сумма транзакций == `balanceRub`; дубль `dedupeKey` — no-op.
- **AC2 Частичное списание.** `amountRub` = net, подпись Робокассы по net,
  `pointsSpent` записан, холд в леджере; cap = цена тарифа при bundle;
  cron и новый заказ возвращают баллы ровно один раз; клиент показывает
  `expired` как истёкший.
- **AC3 100 % баллами.** Без Робокассы, заказ `paid`, `subscriptionEnd`
  продлён у активной организации, партнёрских начислений нет,
  уведомления с «оплачено баллами».
- **AC4 Тумблер.** Включён по умолчанию; выключен — полная сумма; при
  рекурренте недоступен; сотрудник без `hasFullWorkspaceAccess` и ROOT в
  impersonation баллов не видят, сервер их не принимает.
- **AC5 Реферал.** `/r/<code>` → cookie → регистрация → `referredBy`;
  первый paid-заказ → 30 % подписочной части один раз; самореферал /
  старая организация / партнёрская привязка → 0.
- **AC6 Отзыв.** Тариф по mime; начисление только после approve; повторный
  approve — no-op; лендинг показывает только approved + showOnLanding.
- **AC7 ROOT.** Колонка «Баланс ₽», карточка организации, корректировка с
  аудитом, модерация отзывов.
- **AC8 Mini App.** `/mini/balance` и карточка в `/mini/me`.
- **AC9 Проверки.** `npx tsc --noEmit --skipLibCheck`, `npm run lint`,
  `npm test`, `npm run build` — зелёные.

## Ограничения

- Баланс живёт на `Organization`, не на `Account`.
- Баллами оплачивается только подписка (cap = `tariff.priceRub`).
- Холд при создании заказа; возврат при замене заказа и по cron (24 ч).
- Баллы и автосписания несовместимы.
- `accrueForPaidOrder` не трогаем: партнёрские начисления от net-денег.
