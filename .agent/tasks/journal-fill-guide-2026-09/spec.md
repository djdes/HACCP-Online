## Задача (владелец, 2026-09-04)

Короткие пошаговые инструкции «куда нажимать» по интерфейсу для двух
журналов — `/journals/hygiene` и `/journals/climate_control` (потом на все).
Существующая «Инструкция» (`/journals/<code>/guide`) остаётся — она про
правила. Нужно окно-всплывашка с кнопкой «Как заполнить?» справа от
«Инструкция», со ссылками на действия, плюс пошаговое обучение в самом
интерфейсе с затемнением экрана и подсветкой элементов.

Решения владельца:
- иллюстрации — живой спотлайт на реальном UI + мини-копии контролов в окне
  (без PNG-скриншотов);
- окно открывается само один раз на пользователя и журнал (флаг в аккаунте,
  `seenNoticesJson`), дальше — по кнопке;
- на странице документа вход — существующая круглая кнопка внизу справа,
  окно с вкладками «Куда нажимать» / «Правила».

## Acceptance criteria

- AC1 На `/journals/hygiene` и `/journals/climate_control` справа от
  «Инструкция» есть «Как заполнить?»; на `/journals/cleaning` (журнал без
  walkthrough) кнопки нет.
- AC2 Окно показывает шаги из `src/lib/journal-ui-walkthroughs.ts` с
  мини-копиями и вкладку «Правила» с прежним контентом
  `journal-doc-guides.ts`; на 390px — bottom-sheet, помещается в 90vh, тело
  скроллится.
- AC3 «Показать на экране» затемняет страницу, вырезает и подсвечивает
  реальный элемент (вырез = rect цели ±8px), показывает «Шаг N из M»,
  Назад/Далее/Готово, Esc закрывает; шаги без анкора на странице
  пропускаются, `fallbackAnchor` подхватывается на мобиле.
- AC4 Переход список ↔ документ по `?tour=<stepId>` стартует тур на нужном
  шаге, параметр исчезает из URL, `?tab=` не теряется.
- AC5 Первое открытие журнала пользователем открывает окно само; reload и
  другой браузер с тем же аккаунтом — не открывают (`fill-guide:<code>`).
- AC6 Mini App: кнопка в `/mini/journals/<code>` вместо устаревшего
  info-box; круглая кнопка над нижней навигацией в `/mini/documents/<id>`;
  тур подсвечивает карточки/таблицу.
- AC7 Круглая кнопка на журналах без walkthrough ведёт себя как раньше
  (GuideSheet).
- AC8 «К заполнению →» на `/journals/hygiene/guide` и
  `/journals/climate_control/guide` ведёт на список, а не в 404.
- AC9 `npm run typecheck`, `npm run lint`, `npm test` — зелёные.
