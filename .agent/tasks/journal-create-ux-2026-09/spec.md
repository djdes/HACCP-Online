## Задача (владелец, 2026-09-04)

1. Во всех диалогах «Создание документа» поле «Название документа» должно
   предзаполняться «<Название журнала> — <период>» (пример: «Журнал уборки —
   1–15 сентября 2026»). Сейчас в 8 журналах пусто, в ~13 — голое имя.
2. Все выпадающие списки (Select / DropdownMenu / Popover) по сайту —
   современная компактная панель дизайн-системы: под полем, с отступами,
   цветными заголовками групп и иконками, indigo-hover, выбранный пункт
   подсвечен.
3. После выбора должности с 2+ сотрудниками список сотрудников открывается
   сам; с 1 — подставляется; с 0 — подсказка.

Решения владельца: уборка — автоназвание + суффикс « (2)» при совпадении;
автоназвание во всех ~21 диалогах (бессрочные — без периода); автооткрытие
во всех каскадах, включая внутридокументные.

## Acceptance criteria

- AC1 `/journals/cleaning` → «Создать документ»: название = «Журнал уборки —
  <полумесяц>»; при существующем документе с таким названием — « (2)».
- AC2 Годовые журналы (план аудитов, план обучения, СИЗ, дезинсекция,
  жалобы, протокол/отчёт аудита, перечень изделий, ген. уборки, аварии,
  поломки): «… — <год> год»; смена года/даты пересчитывает название, пока
  его не правили руками.
- AC3 Бессрочные (дез. средства, интенсивное охлаждение, стеклоконтроль,
  чек-лист сан. дня): название = имя журнала без периода.
- AC4 Выбор должности с 2+ кандидатами → список сотрудников открывается сам
  (~220 мс) и получает фокус; с 1 — автовыбор; с 0 — hint. Escape закрывает;
  при открытии диалога с уже выбранной должностью список не открывается.
- AC5 Открытый Select: панель под полем на его ширину, rounded-2xl, border
  `#ececf4`, заголовки групп uppercase muted с иконкой, hover `#f5f6ff`,
  выбранный `#eef1ff/#3848c7`, ✓ indigo. DropdownMenu и Popover — та же панель.
- AC6 Mobile 390px: панель не выходит за viewport.
- AC7 Ручные каскады (`usePositionEmployeeCascade`): автооткрытие при 2+,
  автоподстановка первого там, где была; сохраняемые `responsibleTitle`
  не меняются.
- AC8 `npm run typecheck`, `npm run lint`, `npm test` — зелёные.
- AC9 `whats-new-notes.ts` обновлён; SHA — на финальный коммит.
