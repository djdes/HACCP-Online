# Чат: звук и всплывашка, партнёрские переписки, рассылка админа, ночная тема лендинга

Заморожено 2026-09-03. Решения владельца: одна ветка чата на организацию;
админу по партнёрским веткам — тихий Telegram + запись в админке; ночная тема
на лендинге и публичных страницах без переключателя; звук синтезируется в браузере.

## Контекст

- `SupportThread.userId` — ключ ветки (`<userId>` legacy, `guest:<uuid>`). Ответы
  оператора — только свайп-реплаем из Telegram. Клиент видит ответ, только пока
  виджет открыт на экране чата (poll 10 с). Непрочитанного для клиента нет.
- Партнёрский кабинет `/partner/*` не видит чаты своих организаций.
- Лендинг и публичные страницы всегда светлые; кабинет умеет авто-ночь 19:00–7:00
  (`SiteThemeProvider`, `.app-shell[data-app-theme]`, `app-theme.css`).

## Решения

1. Ветки: ключ переименован в Prisma в `key` (`@map("userId")`, без изменения БД).
   Новые значения `org:<orgId>`. Авторизованный чат кабинета работает с веткой
   активной организации; legacy-ветка пользователя с той же организацией
   «усыновляется» (ключ переписывается) при первом обращении. Гости — как раньше.
2. Новые поля: `SupportThread.unreadForClient`, `SupportMessage.authorUserId/authorName/partnerId/broadcastId`.
3. Владелец ветки (партнёр или WeSetup) вычисляется по активной `PartnerClient`
   организации в момент сообщения. Ничего не хранится.
4. Единая серверная библиотека `src/lib/support-threads.ts`: создание/усыновление
   ветки, `postClientMessage` (+ доставка партнёру или админу), `postOperatorMessage`
   (+ доставка организации: Telegram руководству, колокольчик), `markReadByClient`.
   Свайп-реплай бота, ответы ROOT, ответы партнёра и рассылка идут через неё.
5. Клиент: `useIncomingMessages` (poll статуса 25 с / 60 с в фоне), `playIncomingChirp`
   (Web Audio, двухтоновый «у-оу»), `IncomingMessagePopup` (справа снизу над FAB,
   клик открывает чат), бейдж + пульс на кнопке чата. ИИ-помощник — звук при ответе,
   всплывашка, если панель закрыта.
6. Партнёр: `/partner/chats` (список веток организаций, переписка, композер с вложениями,
   «Написать клиенту»), уведомления партнёру: Telegram членам с chat id + письмо на
   `contactEmail`; всплывашка и звук в кабинете партнёра.
7. ROOT: композер в `/root/feedback`, «Написать организации», «Написать всем
   организациям» (ConfirmDialog с typeToConfirm, `broadcastId` для идемпотентности),
   пометка «Ждёт партнёра <бренд> · N ч», счётчики отдельно.
8. Лендинг и публичные страницы: `PublicThemeScope` вешает `app-shell` на `<body>`,
   inline-скрипт до гидрации; правило: авто по времени, если пользователь явно не
   выключил авто в кабинете; иначе — выбранный там режим. Шрифт лендинга не меняется.

## Критерии приёмки

- AC1. Управляющий с legacy-веткой открывает чат — история на месте, ключ ветки `org:<id>`; второй управляющий той же организации видит ту же переписку с именем автора.
- AC2. Ответ оператора при закрытом виджете: звук + всплывашка справа снизу + бейдж на кнопке; клик по всплывашке открывает чат сразу на переписке; после открытия бейдж гаснет.
- AC3. Гость на лендинге: до первого сообщения запросов статуса нет; после ответа оператора — звук и всплывашка на лендинге, клик открывает чат.
- AC4. Ответ ИИ-помощника: звук; при закрытой панели — всплывашка «ИИ-помощник ответил», клик открывает панель.
- AC5. Организация, привязанная к партнёру: сообщение клиента уходит партнёру (Telegram/почта, всплывашка в `/partner/chats`), админу — тихое Telegram «отвечает партнёр» без просьбы ответить; в `/root/feedback` пометка «Ждёт партнёра».
- AC6. Партнёр отвечает и пишет первым из `/partner/chats` — клиент получает сообщение в чат кабинета (звук, всплывашка, Telegram руководству, колокольчик). Партнёр не видит чужие и гостевые ветки; в кабинете клиента пункт «Онлайн-чат» скрыт, POST даёт 403.
- AC7. ROOT отвечает из админки, пишет одной организации и всем сразу; повтор с тем же `broadcastId` не дублирует; отчёт «отправлено: N организаций».
- AC8. Лендинг и публичные страницы ночью (или при `mode=dark` из кабинета) тёмные в палитре кабинета, без вспышки светлого при загрузке; днём — как раньше; шрифт не меняется.
- AC9. `npx tsc --noEmit --skipLibCheck`, `npm run lint`, `npm test` — зелёные; `prisma migrate diff` показывает только ADD COLUMN / CREATE INDEX.
- AC10. `whats-new-notes.ts` обновлён.
