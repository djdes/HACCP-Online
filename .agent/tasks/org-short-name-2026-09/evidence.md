## Что сделано

- **Поле.** `Organization.journalShortName String?`. Разбор в `organization-profile-patch.ts` (пробелы схлопнуты,
  ≤ 120, пусто → `null`), настройки организации (поле, предпросмотр «В шапке журналов: «…»», кнопка «Взять из ЕГРЮЛ:
  …»), партнёрская карточка клиента и `PATCH /api/partner/clients/[orgId]`.
- **Резолвер** `src/lib/org-journal-name.ts`: `config.headerOrgName` → `journalShortName` → `legalProfile.nameShort` →
  `orgDisplayName(name)` → «Организация».
- **Где печатается.** Страница документа (все клиенты через `JournalPaperHeaderRows`, Mini App — та же страница), серверный
  PDF документа, бумажные бланки, архив проверки (`ОТЧЁТ.txt` и сводка), портал инспектора (страница и PDF),
  `/api/reports/pdf` (название из базы, а не из сессии). Крошки и шапка кабинета — полное название.
- **Правка в шапке.** `JournalHeaderEditProvider` монтируется один раз на странице документа; ячейки шапки читают
  контекст. Карандаш по наведению (на телефоне виден всегда, в печати скрыт) → поле в стиле ячейки бланка → для
  организации `ConfirmDialog` «Во всех журналах организации / Только в этом документе» (первое — администратор);
  название документа (`config.headerTitle`) и периодичность (`config.controlPeriodicity`) — только этот документ, без
  лишнего диалога. Права: управление журналами и документ не закрыт.
- **Перенос полей шапки.** `PATCH` документа не берёт поля шапки из присланного `config` (устаревшая копия клиента) и
  переносит прежние; меняют их только поля тела. Хук записи в `src/lib/db.ts` переносит те же поля при любой перезаписи
  конфига (адаптеры TasksFlow, каскад, автозаполнение), если в новом конфиге ключа нет.
- **PDF.** Название документа из шапки печатается в штампах ХАССП: общий `drawJournalHeader`, шесть своих штампов в
  `document-pdf.ts` и штампы чек-листов вентиляции и санитарного дня (`cleaning-ventilation-checklist-pdf.ts`,
  `sanitary-day-checklist-pdf.ts`). Бумажные бланки показывают сокращённое название и на экране, и в PDF.
- **«Что нового»:** категория «Шапка журналов».
