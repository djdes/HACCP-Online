# org-short-name-2026-09 — сокращённое название организации в журналах

Источник: план `cached-nibbling-magpie.md`, Задача 2 (ТЗ п.4, п.5, п.6 — шапка). Заморожено 2026-09-15.

## Проблема
В шапке каждого журнала и в PDF печатается полное название организации из `Organization.name`
(или заглушка). Заказчик хочет короткое название для журналов, править его прямо в таблице документа
и применять ко всем журналам сразу. Кнопки «применить ко всем» и правки шапки в документе нет.

## Acceptance criteria
- **AC1** В `/settings/organization` под «Название организации» поле «Сокращённое название для журналов» (≤120,
  подсказка «Печатается в шапке каждого журнала и в PDF; пусто — краткое название из ЕГРЮЛ или полное», кнопка
  «Взять из ЕГРЮЛ: …» при наличии `nameShort`); сохраняется/очищается через `PATCH /api/settings/organization` и
  партнёрский `PATCH /api/partner/clients/[orgId]`.
- **AC2** Резолвер: `config.headerOrgName` документа → `journalShortName` → `legalProfile.nameShort` →
  `orgDisplayName(name)` → «Организация»; никогда «Тест» (юнит-тест).
- **AC3** Шапка на сайте (все клиенты документов), в Mini App, серверном PDF документа, бумажных бланках,
  регуляторном бандле, инспекторском портале, `/api/reports/pdf` показывает резолвленное имя (+ метка точки
  `withBuildingLabel`). Крошки и шапка кабинета — полное название.
- **AC4** В документе (права на управление журналами): hover по ячейке организации → карандаш → инлайн-ввод →
  `ConfirmDialog` «Во всех журналах организации / Только в этом документе»; первое пишет
  `Organization.journalShortName` и очищает override документа, второе — `config.headerOrgName`; без прав карандаша
  нет; в печати скрыт.
- **AC5** Carry-over: сохранение строк (PATCH `config` без ключа) не стирает `headerOrgName`.
- **AC6** Той же механикой редактируются название документа и периодичность контроля (scope «этот документ»).
- **AC7** typecheck/lint/test чистые; e2e локально; прод read-only (форма и шапка).

## Ограничения
- Схема: только `Organization.journalShortName String?` (nullable, деплой делает `prisma db push`).
- `journal-document-header.tsx` — правка только внутри ячеек шапки, пропсы `orgName`/`title`/`controlPeriodicity`
  сохраняются; 36 клиентов не трогаем.
- Mini App получает паритет через ту же страницу документа (П-3).
- e2e только на `wesetup_e2e` (localhost:5432), никогда на `.env` (5433 = прод).
