## Задача (владелец, 2026-09-18)

В журналах с оборудованием — редактирование строки прямо из таблицы: клик
по названию открывает окно с названием, диапазоном и QR-кодом с печатью.
При выделении чекбоксами — напечатать много QR на одном листе A4.

Решения владельца:
- журналы: холодильное оборудование (`cold_equipment_control`) + климат
  (помещения, `climate_control`);
- несвязанная со справочником строка при сохранении автоматически
  создаётся в справочнике «Оборудование» и связывается;
- правка названия/диапазона в журнале синхронизируется в справочник.

## Acceptance criteria

- AC1 В cold-журнале клик по названию строки открывает диалог с названием,
  режимом, пресетом, «от/до»; сохранение меняет строку и запись
  справочника `Equipment` (name/tempMin/tempMax).
- AC2 Несвязанная строка после сохранения получает `sourceEquipmentId`,
  запись появляется в `/settings/equipment`, диалог показывает QR.
- AC3 В диалоге связанной строки виден QR; ссылка внутри QR =
  `/equipment-fill/<id>?token=…`, токен проходит `verifyEquipmentQrToken`.
- AC4 «Плакат A4» / «Наклейка» открывают страницу плакатов с одним
  объектом; `autoprint=1` вызывает `window.print()`.
- AC5 Выделив N строк, кнопка «QR-коды» ведёт на
  `/settings/qr-posters?kind=equipment&layout=sheet&ids=…`; страница
  показывает ровно N наклеек; печатная раскладка — несколько на лист
  (`@page A4`, `break-inside: avoid`, 3 колонки).
- AC6 Климат: клик по названию помещения открывает карточку помещения; в
  секции «Климат» есть QR со ссылкой `/room-fill/<id>?token=…`.
- AC7 `/settings/equipment/qr-sheet` редиректит на новую раскладку.
- AC8 `/mini/documents/<coldDocId>` показывает те же кнопки (тот же клиент).
- AC9 `npx tsc --noEmit --skipLibCheck` и `npm run lint` — чистые.
