# Исправления в журналах (сентябрь 2026)

Проверены все 35 журналов на компьютере и телефоне. На проде: сборка 09d03bfb, смоук 77 из 77.
Формат: что было → что стало.

## Общее для всех журналов
1. **Карточки на телефоне.** Запись нельзя было посмотреть: тап сразу открывал правку. → Тап раскрывает карточку со всеми полями, правка — кнопкой «изменить».
2. **Права рядового сотрудника.** Он видел «Создать документ», «Настройки», «Удалить», а сервер их отбивал; в ТО, поверке, поломках, охлаждении, перечне стекла, дезсредствах и генуборках не мог внести ни одной записи — окно закрывалось, запись пропадала. → Лишние кнопки скрыты; записи вносить можно, а название, статус и период документа меняет только руководитель.
3. **Период документа** нельзя было изменить после создания. → Даты «с … по …» меняются в «Настройках журнала», при сокращении показывается, сколько записей окажется вне периода.
4. **Уволенные сотрудники** пропадали из старых журналов и печати (гигиена, здоровье, медкнижки, СИЗ, приёмка). → В сделанных записях остаются с ФИО, в списки выбора не попадают.
5. **Ошибки сохранения** не показывались: окно зависало или закрывалось, как будто сохранило (аварии, прослеживаемость, приёмка, металлопримеси, СИЗ, фритюр, журнал уборки). → Показывается причина, окно не закрывается.
6. **Удаление без вопроса**: помещения, оборудование, строки и сотрудники удалялись вместе с замерами и отметками. → Везде подтверждение с числом того, что пропадёт.
7. **«Сегодня» по Гринвичу**: ночью записи уходили вчерашним числом, просрочка считалась со сдвигом (аварии, охлаждение, стекло, поломки, мойка оборудования, медкнижки, СИЗ, аудиты). → Считается по местному времени.
8. **Быстрый ввод терял данные**: сохранялась только последняя из нескольких быстрых отметок (журнал уборки, генуборки, дезсредства, ТО, поверка, протокол аудита). → Сохраняются все.

## Не сделано, нужны отдельные задачи
- **Журнал уборки:** коды уборщиков С1…СN привязаны к месту в списке — при смене состава старые подписи начинают указывать на другого человека. Нужна смена формата хранения с переносом старых документов. С телефона не открывается карточка помещения.
- **УФ-лампа:** второй и третий сеанс за день нельзя исправить или удалить прямо в таблице.
- **Дезсредства:** у расхода нет полей «за период с … по …»; с телефона нельзя удалить карточку поступления или расхода.
- **График ТО и поверка** не связаны со справочником оборудования: переименование в справочнике до графика не доходит.
- **План аудита, протокол и отчёт** не связаны между собой: несоответствия переносятся вручную.
- **Кнопки управления у рядового сотрудника** скрыты не во всех журналах: остались жалобы, стекло, УФ и ещё несколько со своими списками документов.
- **«Сегодня» в браузере** считается по часовому поясу устройства, а на сервере — по поясу организации. У сотрудника в другом поясе возможна ошибка «не сегодня».
