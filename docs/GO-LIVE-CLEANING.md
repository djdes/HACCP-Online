# Cleaning Go-Live для уборщицы — чеклист

**Дата:** 2026-05-08
**Цель:** запустить журнал уборки сегодня для одной уборщицы. После
проверки — раскатить на остальных + поваров.

---

## Что уже работает (полная цепочка)

```
[Менеджер]                         [Уборщица]                    [Менеджер]
     ↓                                  ↓                              ↓
Настроил                       Открыла задачу в                Видит в
помещения  → bulk-assign →    TF Mini App  →  фото каждого  → /settings/
                                wizard           шага        →    audit
                                (можно            ↓                trail
                                  пропустить)    нельзя
                                                  выйти
                                                  без фото
```

### Защита от «протыкивания» — что уже залочено в коде

- ✅ **Step order**: уборщица не может перейти к шагу 2 не подтвердив шаг 1 ([task-fill-client.tsx:229](src/app/task-fill/%5BtaskId%5D/task-fill-client.tsx#L229))
- ✅ **Photo required**: если `Room.requirePhoto = true` → кнопка «Сделал» заблокирована до загрузки фото на КАЖДОМ шаге ([task-fill-client.tsx:236](src/app/task-fill/%5BtaskId%5D/task-fill-client.tsx#L236))
- ✅ **Audit log per step**: каждое нажатие «Сделал» пишется в `AuditLog` с timestamp, photoUrl, длительностью с момента открытия формы ([api/task-fill/[taskId]/step/route.ts](src/app/api/task-fill/%5BtaskId%5D/step/route.ts))
- ✅ **HMAC token**: токен заполнения подписывается per-integration secret — нельзя подделать запись с чужого аккаунта
- ✅ **Comment / signature gating**: если шаг требует комментарий или подпись — кнопка блокируется до заполнения ([task-fill-client.tsx:240](src/app/task-fill/%5BtaskId%5D/task-fill-client.tsx#L240))
- ✅ **No skip via direct URL**: задача открывается только по rowKey-привязке, скрипты `task-fill-token` валидируют интеграцию
- ✅ **Photo evidence trail**: фото складываются в `/uploads/...`, attachments видны в `/settings/audit` напротив каждого шага

## Шаги настройки (5 минут)

### 1. Заведи помещения (если ещё не)

`/settings/buildings`:

1. Нажми **«Добавить здание»** → введи название (например «Главная точка»)
2. Внутри здания нажми **«+ Добавить помещение»** на каждое физ.помещение:
   - Гостевая зона
   - Кухня / горячий цех
   - Мойка
   - Бар
   - Склад

### 2. Настрой каждое помещение

В `/settings/buildings`, на каждой комнате нажми **«✏ Настроить»**. Откроется большой диалог:

| Поле | Что вводить |
|------|------------|
| **Название** | как уже есть |
| **Тип** | Кухня / Бар / и т.д. |
| **Моющие средства** | например «Хлоргексидин 0.05% + Sanit» |
| **📸 Требовать фото на каждом шаге** | **ВКЛЮЧИ** — это твой ключевой контроль |
| **Текущая уборка → шаги** | напр.: «Протри столы → Подмети пол → Вынеси мусор» |
| **Текущая → когда?** | таб «Каждую неделю» → выбери Пн-Пт |
| **Генеральная → шаги** | напр.: «Демонтировать съёмные части → Промой в горячей воде → Дезинфицируй → Собери» |
| **Генеральная → когда?** | таб «По датам месяца» → нажми **«⭐ Последний день месяца»** |

Сохрани. Повтори для каждого помещения.

### 3. В журнале уборки переключи на rooms-mode

Открой `/journals/cleaning/documents/<id>` → прокрути вниз до карточки **«Режим уборки · Race-задачи на помещения»**:

1. Поставь галочку **«Включить»** (это активирует rooms-mode)
2. **Выбери помещения** — отметь чекбоксами те 4-5 что только что настроил
3. **Выбери уборщиков** — отметь свою уборщицу (можно одну для теста)
4. **Выбери контролёра** — себя или заведующую (он будет получать сводную задачу-проверку в конце дня)
5. Сохрани

### 4. Жми «Заполнить по плану»

В sticky-toolbar над матрицей нажми **«Заполнить по плану»**. Матрица заполнится T'шками и G'шками согласно расписанию помещений (которое ты только что задал).

Проверь визуально что:
- В будни ячейки = T (зелёные/коричневые)
- В последний день месяца = G
- Выходные = «/» если пометил «По будням»

### 5. Жми «Отправить всем»

Кнопка **«Отправить всем»** на дашборде или в журнале. Создаются TF-задачи для каждой выбранной комнаты × уборщицы.

## Проверка на стороне уборщицы

Уборщица открывает **TasksFlow Mini App** в Telegram → видит задачи:

- «Уборка · Кухня» (для теста — 1 задача)
- «Уборка · Бар» (вторая)
- ...

Кликает первую → открывается WeSetup task-fill (через task-fill-url).
Видит **wizard** с шагами по `currentScope` помещения:

```
1. Протри столы            [ Загрузить фото ]
                            [Сделал] (заблокирована пока нет фото)
```

Загружает фото → кнопка активна → жмёт «Сделал» → переход к шагу 2.

В конце — финальный submit. Запись попадает в `JournalDocumentEntry`,
матрица заполняется (инициалами уборщицы в ячейке сегодня), TF-задача
помечена completed.

- Compliance ring: «X из Y журналов заполнено сегодня»
- Карточка `cleaning`: зелёный когда все TF-задачи закрыты
- Если уборщица закрыла задачу 1, но 3 остальные active — статус:

каких нет, какие фото загрузили.

## Если что-то пошло не так

### TF-задачи не создались

Проверь:
1. Интеграция активна? `/settings/integrations/tasksflow` → должна быть зелёная плашка «Подключено»
2. Уборщица привязана к TF? `/settings/users` → её Telegram должен быть синим бейджиком
3. Bulk-assign не блокируется rate-limit'ом? Если меньше 30 сек назад делал «Отправить» — подожди.

### Уборщица не видит задачи в TF

1. Открыла ли она бот `@wesetupbot` в Telegram и нажала /start?
2. Если задачи нет в Mini App — push прошёл, но синхронизация TF→bot могла отстать. Скажи ей открыть TF webapp (https://tasksflow.ru) напрямую — увидит.

### Кнопка «Сделал» не активируется

Возможные причины:
- Фото не загружено (если `Room.requirePhoto=true`)
- Не открыта камера / разрешения
- Сеть упала на upload — попроси перезагрузить

## После успешного запуска у уборщицы

1. **Дай всем уборщикам** — добавь второго в `selectedCleanerUserIds`. Race-mode (если включить «Race-задачи») = «кто первый закрыл, тот забрал».
2. **Раскатывай на поваров** — первый журнал для них: `health_check` (с утренним замером t° тела) или `hygiene` (отметка о здоровье перед сменой).
3. **Соц.учр. флоу** (если будут школы/сады в подписчиках) — `finished_product` (бракераж) — самый critical for них.
4. **Постепенная активация остальных 30+ журналов** — через `/settings/journals` `taskFlowMode` toggle.
