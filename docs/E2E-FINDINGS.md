# E2E Quick Start walkthrough — findings

Test: новая компания «E2E QuickStart Кафе» зарегистрирована через
Playwright, прохожу /settings/onboarding путь как обычный менеджер.

## Confirmed bugs (blocking UX)

### 🔴 BUG-1: Equipment диалог — required Цех при отсутствии Цехов
**Где**: /settings/equipment → «Добавить оборудование»

**Симптом**: Поле «Цех / участок» обязательное (отмечено ⨯), но
у новой организации НЕТ ни одного цеха. Кнопка «Создать» становится
disabled. Юзер не может создать оборудование пока не пойдёт в
другой раздел и не заведёт цех — и нигде это не объясняется.

**Fix**: либо
  • Inline-link «+ Создать новый цех» внутри select'а (открывает
    мини-форму прямо здесь)
  • Либо сделать Цех опциональным (areaId = null), как в других
    раннее-настроечных формах
  • Либо в самом диалоге показать «У вас нет цехов — сначала
    создайте → /settings/buildings», disabled-state с CTA

### 🔴 BUG-2: PageGuide отсутствует на ключевых setup-страницах
Я добавил PageGuide только на 3 страницы (journals, auto-journals,
tasksflow). На остальных — НЕТ объяснения «что делать»:
  • /settings/organization
  • /settings/users
  • /settings/buildings
  • /settings/equipment
  • /settings/products
  • /settings/journal-responsibles (есть, но нужно проверить)
  • /settings/journal-pipelines
  • /settings/journal-checklists

**User flow**: попадает с Quick Start, не понимает с чего начать.
Несмотря на placeholder-тексты, новичок теряется.

**Fix**: добавить PageGuide на оставшиеся 7 страниц с короткими
шагами «что делать на этой странице».

### 🔴 BUG-3: Очерёдность Quick Start не отражает зависимости
Pipeline показывает 6 этапов в линейном порядке, но реальные
зависимости перекрёстные:
  • Оборудование требует Цех → нужно зайти в Buildings раньше
  • Ответственные за журналы требуют и Должности и Сотрудников
  • Документы требуют Активные журналы

В Quick Start UI нужно либо
  • показывать «зависит от» на заблокированных пунктах
  • либо disable пункт пока зависимость не выполнена + tooltip

### Заметки на полях
- /settings/organization: форма работает, нет PageGuide
- /settings/users: пусто на старте. Категории «Руководство 0»
  / «Сотрудники 0» — заголовки есть, но position'ов 0. Нужно
  жать «+» чтобы добавить должность. Это интуитивно, но без
  PageGuide новичок может пропустить
- Default positions удалены (good — соответствует требованию
  «не должно быть default»)
