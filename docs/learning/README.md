# 📚 Учебная мастерская

Папка с обучающими материалами лично для тебя. Не для прода, не для
других сотрудников — только твоё пространство, чтобы расти.

## Что внутри

| Файл | Что это | Когда открывать |
|---|---|---|
| **[`index.html`](./index.html)** | Главный учебник «Wesetup Codex» — красивая HTML-книга в 12 главах с примерами из твоего же кода | Каждый день, главу за главой |
| **[`roadmap.md`](./roadmap.md)** | Пошаговый план на 6 недель + список курсов, видео, доков | Раз в неделю, проверять чеклист |
| `README.md` | Этот файл | Сейчас |

## Как начать прямо сейчас

1. **Открой [`index.html`](./index.html)** в браузере:
   - Двойной клик по файлу.
   - Или в VS Code: правой кнопкой → «Open with Live Server»
     (нужно поставить расширение Live Server).
   - Или просто перетащи файл в браузер.

2. **Прочитай Вступление и Главу I** (карта проекта). Это 20 минут.

3. **Открой [`roadmap.md`](./roadmap.md)** — посмотри программу
   первой недели.

4. **Выбери первый ресурс** из списка теории — начни смотреть/читать.

## Как работать с учебником

- **Главы читать по порядку** в первый проход (I → XII).
- После — заходи в нужную главу как в справочник, когда что-то
  забыл.
- **Каждую главу подкрепляй практикой.** Не открыл код — не считается,
  что читал.
- В сайдбаре книги — индикатор прогресса. Дочитал главу → закрасилось.
- Все примеры кода — **реальные**, из твоего же `src/`. Можно
  открыть файл и проверить.

## Как работать с roadmap

- В начале недели открой соответствующий раздел.
- Чекбоксы (`- [ ]`) — можно прямо в файле менять на `- [x]`, чтобы
  следить за прогрессом.
- Если какой-то ресурс не зашёл — забей, открой следующий из
  списка. Цель — выучить тему, а не пройти конкретный курс.
- В конце недели — открой соответствующий чеклист из
  [Главы XII](./index.html#ch-12). Что не отмечается — добей.

## Если что-то непонятно

1. Прочитай ещё раз — медленно.
2. Открой соответствующий файл в проекте, потыкай руками.
3. Загугли термин — на английском в Stack Overflow, на русском в
   doka.guide.
4. Спроси AI-ассистента (Claude/ChatGPT) — но проверяй то, что он
   говорит, на реальном коде.
5. Если совсем застрял — отметь это место («не понял что такое
   X»), пропусти, иди дальше. Часто понимание приходит позже,
   когда прочитал больше контекста.

## Что НЕ делать

- ❌ Не пытайся выучить всё за выходные. Сгоришь.
- ❌ Не пиши код, который не понимаешь, даже если он работает.
- ❌ Не заучивай — фокусируйся на понимании.
- ❌ Не сравнивай свой темп с чужим. Все разные.
- ❌ Не пропускай практику. Чтение без рук — иллюзия знания.

## Что делать

- ✅ Каждый день кодь по чуть-чуть — хоть 30 минут.
- ✅ Веди свои заметки. В этой же папке можно сделать `notes.md`.
- ✅ После каждой недели возвращайся к чеклисту [Главы XII](./index.html#ch-12).
- ✅ Когда что-то откроется — сохрани этот «эврика»-момент. Это и есть
  обучение.

## Этот учебник — твой

Если найдёшь что-то полезное в процессе — дописывай. Свои примеры,
свои ошибки, свои решения. Лучший учебник — тот, который ты переписал
сам под себя.

Если найдёшь ошибки или неточности в существующих главах — правь
прямо в `index.html`. Это твоя книга.
