# Journal `audit_report` — Отчет о внутреннем аудите

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Сводный отчёт по итогам аудита (1-2 страницы) — для руководства,
сертификационных органов, проверок РПН. Содержит выводы о
функционировании ХАССП-системы.

## Колонки

| # | Поле | Тип |
|---|------|-----|
| 1 | № отчёта | text (auto) |
| 2 | Период аудита (от-до) | daterange |
| 3 | Аудитор | text |
| 4 | Объекты аудита | text (multi) |
| 5 | Кол-во проверенных процессов | number (auto из протоколов) |
| 6 | Кол-во найденных несоответствий | number (auto) |
| 7 | Распределение по серьёзности (минор/major/крит) | text |
| 8 | Общий вывод (Эффективна / Требует доработки / Не эффективна) | select |
| 9 | Рекомендации руководству | text (long) |
| 10 | Подпись аудитора | signature |
| 11 | Подпись утвердившего | signature |
| 12 | PDF-отчёт прикреплён | photo/file |

## Ритм

Per полный аудит (квартально / полугодие / годовой).

## TasksFlow flow

- **Type:** event-driven (rolling); generated после закрытия audit_protocol(ов)
- **rowKey:** `audit-report::{period}`

## Compliance rule

Не daily-rule. Дашборд: «дата последнего аудита» + статус ХАССП-системы.
