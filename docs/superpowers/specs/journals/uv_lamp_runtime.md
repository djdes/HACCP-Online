# Journal `uv_lamp_runtime` — Журнал учета работы УФ-бактерицидной установки

**Tier:** C (ХАССП-рекомендуемый, обязателен где УФ установлено)

## Назначение

УФ-бактерицидные лампы имеют ограниченный ресурс (обычно 8000 часов).
Превышение → лампа теряет эффективность, обеззараживание не работает.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Помещение / зона установки | text |
| 2 | Дата установки лампы | date |
| 3 | Дата/время включения | datetime |
| 4 | Дата/время выключения | datetime |
| 5 | Длительность работы (мин) | number (auto) |
| 6 | Кумулятивная наработка (часы) | number (auto) |
| 7 | Дата замены лампы | date |
| 8 | Подпись | signature |

## Ритм

- **Daily:** включение/выключение фиксируется автоматически (если IoT-датчик)
  или вручную сотрудником
- **Per-event:** при замене лампы (когда наработка >= 8000 ч)

## Pipeline (TF task)

При замене:
1. Шаг 1 — Зафиксируй наработку старой лампы (number)
2. Шаг 2 — Установи новую лампу (photoMode: required)
3. Шаг 3 — Сбрось счётчик

## Compliance rule

При наработке > 7500 ч — жёлтый сигнал «приближается замена».
При > 8000 ч — красный, блокирующий.

## Связи

- Если есть `Equipment` с kind=uv_lamp → таски авто-fan-out
- При замене → запись в **disinfectant_usage** (если лампа в комплекте с раствором)
