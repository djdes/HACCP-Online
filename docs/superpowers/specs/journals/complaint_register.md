# Journal `complaint_register` — Журнал регистрации жалоб

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Регистрация всех жалоб клиентов: качество еды, обслуживание, гигиена,
найденные посторонние предметы. Источник для CAPA-tickets и анализа
системных проблем.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата получения | date |
| 2 | Источник (зал / телефон / Email / соцсети / агрегатор) | select |
| 3 | ФИО / контакт клиента | text |
| 4 | Описание жалобы | text (long) |
| 5 | Категория (качество еды / сервис / гигиена / другое) | select |
| 6 | Принятые меры | text |
| 7 | Результат / статус | select (Решено / В работе / Эскалировано) |
| 8 | Ответственный | text (auto) |
| 9 | Подпись | signature |
| 10 | Прикреплённые материалы (фото блюда / переписка) | photo/file |

## Ритм

Event-driven.

## TasksFlow flow

- **Type:** event-driven (rolling); кнопка «+ жалоба» в дашборде
- **rowKey:** `complaint::{timestamp}`

## Связи

- При категории «гигиена» или «качество еды» → auto-CAPA-ticket
- Эскалация menedzheru / owner'у через notifications

## Compliance rule

Не daily-rule. Дашборд: «N открытых жалоб», «средний срок решения».
