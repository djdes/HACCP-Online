# Journal `audit_plan` — План-программа внутренних аудитов

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Годовой план внутренних аудитов ХАССП-системы: какие процессы проверяются,
когда, кто аудитор, какой checklist используется.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | № | number (auto) |
| 2 | Объект аудита (процесс / зона) | text |
| 3 | Дата плановая | date |
| 4 | Аудитор (ФИО) | text |
| 5 | Checklist (ссылка на док) | text/file |
| 6 | Статус (Запланирован / Выполнен / Просрочен) | select (auto) |
| 7 | Подпись утвердившего | signature |

## Ритм

Yearly plan (составляется в начале года). Аудиты обычно ежеквартальные
или полугодовые.

## TasksFlow flow

- **Type:** plan-document (не задача); reminders за 7 дней до плановой даты
- **rowKey:** `audit-plan::{year}::{n}`

## Связи

Каждый запланированный аудит → создаёт запись в `audit_protocol` при выполнении.
