# Journal `breakdown_history` — Карточка истории поломок

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Per-equipment карточка со списком всех поломок и ремонтов. Помогает
видеть проблемное оборудование (часто ломается → надо менять).

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Оборудование | text (auto, primary key) |
| 2 | Дата поломки | date |
| 3 | Описание неисправности | text |
| 4 | Принятые меры (ремонт / замена / списание) | select |
| 5 | Стоимость ремонта, ₽ | number |
| 6 | Подрядчик / исполнитель | text |
| 7 | Дата восстановления | date |
| 8 | Подпись отв. лица | signature |
| 9 | Прикреплённые фото / акты | photo |

## Ритм

Event-driven (при поломке).

## TasksFlow flow

- **Type:** event-driven, rolling
- **rowKey:** `breakdown::{equipmentId}::{timestamp}`

## Compliance rule

Не daily-rule. Дашборд показывает «N оборудования в ремонте сейчас» (где
дата поломки заполнена, а дата восстановления — нет).
