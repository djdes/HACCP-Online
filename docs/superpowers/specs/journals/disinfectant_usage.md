# Journal `disinfectant_usage` — Журнал учета дезинфицирующих средств

**Tier:** C (ХАССП-рекомендуемый, лучшая практика)

## Назначение

Контроль расхода и хранения дезсредств. Связь с журналом мойки/дезинфекции
оборудования (когда, какое средство, какая концентрация, срок годности).

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата | date |
| 2 | Препарат (марка) | text |
| 3 | Дата выпуска | date |
| 4 | Срок годности | date |
| 5 | Полученное количество | number |
| 6 | Расход (списание) | number |
| 7 | Остаток | number (auto) |
| 8 | Подпись ответственного | signature |
| 9 | Целевое назначение | select (мойка пола / посуды / оборудования / разделочных досок) |

## Ритм

Event-driven (при получении новой партии + при каждом списании).

## TasksFlow flow

- Event-driven через rolling button
- rowKey: `disinfectant::{timestamp}`

## Связи

При списании в этом журнале → автоматически добавляется в **equipment_cleaning**
запись «использовано {препарат} {объём}» если идёт мойка оборудования.
