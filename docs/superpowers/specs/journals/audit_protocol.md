# Journal `audit_protocol` — Протокол внутреннего аудита

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Per-аудит протокол: что проверено, какие найдены несоответствия,
какие приняты корректирующие действия.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | № протокола | text (auto) |
| 2 | Дата аудита | date |
| 3 | Объект аудита (link to audit_plan) | text |
| 4 | Аудитор | text |
| 5 | Найденные несоответствия | text (long) |
| 6 | Серьёзность (минор / major / критика) | select |
| 7 | Корректирующие действия | text |
| 8 | Срок устранения | date |
| 9 | Ответственный за устранение | text |
| 10 | Статус (открыто / закрыто) | select |
| 11 | Дата закрытия | date |
| 12 | Подпись аудитора | signature |
| 13 | Подпись отв. лица | signature |
| 14 | Прикреплённые файлы | photo/file |

## Ритм

Event-driven (per аудит). Обычно 4 / 2 раза в год.

## TasksFlow flow

- **Type:** event-driven (rolling); создаётся из audit_plan record
- **rowKey:** `audit-protocol::{auditPlanRowKey}`

## Связи

- Несоответствия → CAPA-tickets
- Закрытие протокола → запись в `audit_report`
