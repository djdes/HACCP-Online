# Journal `equipment_cleaning` — Журнал мойки и дезинфекции оборудования

**Tier:** C (ХАССП-рекомендуемый)
**СанПиН:** п. 4.10-4.16 (общие требования к мойке)

## Назначение

Фиксация ежедневной/посменной мойки кухонного оборудования (плиты,
жарочные шкафы, тестомесы, мукопросеиватели, разделочные доски). По ХАССП —
критичная контрольная точка против перекрёстного загрязнения.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата | date |
| 2 | Оборудование | text (auto из equipment) |
| 3 | Время начала мойки | time |
| 4 | Время окончания | time |
| 5 | Использованное средство (марка) | text (autocomplete из disinfectant_usage) |
| 6 | Концентрация / разведение | text |
| 7 | Исполнитель | text (auto из staff) |
| 8 | Контроль качества (внешний осмотр) | select (ОК / переделать) |
| 9 | Подпись контролёра | signature |

## Ритм

Daily / посменно (зависит от оборудования).

## Pipeline (TF task)

1. Шаг 1 — Подготовь оборудование к мойке (отключи, разбери)
2. Шаг 2 — Промой средством {препарат} (concentration field)
3. Шаг 3 — Дезинфицируй
4. Шаг 4 — Промой проточной водой
5. Шаг 5 — Просуши

photoMode: required на шаге 5 (фото вымытого оборудования).

## TasksFlow flow

- **Type:** N задач/день (per active equipment with cleaning-rule)
- **rowKey:** `equipment::{equipmentId}::{date}`

## Связи

- Расход средств → списание из **disinfectant_usage**
- Найдены загрязнения → CAPA-ticket
