# Journal `glass_items_list` — Перечень изделий из стекла и хрупкого пластика

**Tier:** C (ХАССП-рекомендуемый)
**Связь:** работает в паре с `glass_control` (тот — еженедельный обход; этот — справочник позиций)

## Назначение

Реестр (не журнал-таблица событий) всех стеклянных и хрупких пластиковых
изделий в производственной зоне: лампы, окна, посуда, прозрачные крышки
контейнеров. Без этого справочника `glass_control` нечего проверять.

## Структура (per item)

| # | Поле | Тип |
|---|------|-----|
| 1 | № | number (auto) |
| 2 | Расположение | text |
| 3 | Описание | text |
| 4 | Материал (стекло / поликарбонат / акрил / иное) | select |
| 5 | Производитель | text |
| 6 | Дата установки | date |
| 7 | Состояние при установке | text |
| 8 | Прикреплённое фото | photo |
| 9 | Активна (да/нет) | boolean (auto: false если разбита) |

## Ритм

Event-driven: при добавлении нового изделия / удалении (разбито,
заменено).

## Pipeline (TF task)

При добавлении:
1. Шаг 1 — Сфотографируй позицию (photoMode: required)
2. Шаг 2 — Заполни описание + расположение

## TasksFlow flow

- **Type:** event-driven (rolling); кнопка «+ позиция» в дашборде
- **rowKey:** `glass-item::{itemId}`

## Compliance rule

Реестр обновляется по ХАССП-плану. Дашборд: «N активных позиций» —
не падает в красный, информационный счётчик.

## Связи

- Каждая позиция → объект проверки в `glass_control` (weekly)
- При статусе «Разбито» в `glass_control` → запись здесь обновляется
  (active=false), позиция уходит из списка обхода
