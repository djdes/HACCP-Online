# Journal `accident_journal` — Журнал учета аварий

**Tier:** C (ХАССП-рекомендуемый, обязателен для крупных предприятий)

## Назначение

Регистрация аварий и инцидентов: отключение электричества, поломка
холодильников (с потерей продукта), нарушение водоснабжения, ЧП с
сотрудниками (отравление, травма).

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата и время инцидента | datetime |
| 2 | Тип (поломка / ЧП / нарушение цепи холода / другое) | select |
| 3 | Описание | text |
| 4 | Затронутое оборудование / помещение | text |
| 5 | Пострадавшие сотрудники (если есть) | text |
| 6 | Принятые меры | text |
| 7 | Результат / последствия | text |
| 8 | Ответственный | text (auto) |
| 9 | Дата восстановления | datetime |
| 10 | Подпись | signature |
| 11 | Прикреплённые акты / фото | photo/file |

## Ритм

Event-driven.

## TasksFlow flow

- **Type:** event-driven; immediate (admin кнопка «инцидент»)
- **rowKey:** `accident::{timestamp}`

## Связи

- При типе «нарушение цепи холода» → auto-CAPA + проверка списания
  продукции (`product_writeoff`)
- При ЧП с сотрудником → запись в **staff_training** (внеплановый инструктаж)

## Compliance rule

Не daily-rule. Open accidents показываются на дашборде.
