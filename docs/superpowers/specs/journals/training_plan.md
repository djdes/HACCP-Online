# Journal `training_plan` — План обучения персонала

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Годовой план обучения per-сотрудник: какие темы, когда, ответственный
инструктор. Связан с **staff_training** (там фиксируется факт прохождения).

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | № | number |
| 2 | Сотрудник / должность / группа | text |
| 3 | Тема обучения | text |
| 4 | Тип (вводный / повторный / целевой / переаттестация) | select |
| 5 | Месяц / дата плановая | date |
| 6 | Ответственный (инструктор) | text |
| 7 | Длительность | number (часы) |
| 8 | Учебные материалы (ссылки) | text/file |
| 9 | Подпись утвердившего | signature |

## Ритм

Yearly plan; per-event reminders за 30/7 дней до плановой даты.

## Связи

При наступлении плановой даты → задача «провести инструктаж» в `staff_training`.
