# Journal `staff_training` — Журнал регистрации инструктажей и обучения

**Tier:** C (ХАССП-рекомендуемый, обязателен по ТК РФ ст. 225)

## Назначение

Регистрация прохождения инструктажей: вводный, первичный (на рабочем
месте), повторный (раз в полгода), внеплановый (при ЧП), целевой
(под конкретное задание).

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата | date |
| 2 | Тип инструктажа (вводный / первичный / повторный / внеплановый / целевой) | select |
| 3 | Тема | text |
| 4 | Сотрудник | text (auto) |
| 5 | Должность | text (auto) |
| 6 | Подпись инструктируемого | signature |
| 7 | Инструктор (ФИО) | text (auto = current user) |
| 8 | Подпись инструктора | signature |
| 9 | Прикреплённые материалы (программа / тест) | photo/file |

## Ритм

Event-driven + плановые повторные раз в 6 мес.

## TasksFlow flow

- **Type:** event-driven (rolling); плановые reminder через cron
- **rowKey:** `training::{userId}::{type}::{date}`

## Compliance rule

Сотрудник без повторного инструктажа > 6 мес → желтый сигнал.

## Связи

- При найме нового сотрудника → автоматически создаются 2 задачи:
  «провести вводный» + «провести первичный»
