# Journal `equipment_maintenance` — График профилактического обслуживания (ППР)

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Плановое обслуживание оборудования (чистка фильтров, замена прокладок,
мойка змеевиков холодильников). Защита от выходов из строя в самые
неподходящие моменты.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Оборудование | text (auto) |
| 2 | Тип работы (A/B/...) | select (тип А = простое, B = сложное) |
| 3 | Дата плановая | date |
| 4 | Дата фактическая | date |
| 5 | Исполнитель | text (auto или подрядчик) |
| 6 | Описание работ | text |
| 7 | Использованные материалы / запчасти | text |
| 8 | Подпись | signature |
| 9 | Следующая дата ППР | date (auto) |

## Ритм

Per-equipment, periodicity = config.maintenanceMonths (обычно 1, 3, 6, 12 месяцев).

## TasksFlow flow

- **Type:** event-driven (cron генерит за 7 дней до плановой даты)
- **rowKey:** `ppr::{equipmentId}::{plannedDate}`

## Compliance rule

Просроченные → красный знак на дашборде. Считаем «N единиц с просроченным ППР».

## Связи

При нахождении дефекта → запись в **breakdown_history**.
