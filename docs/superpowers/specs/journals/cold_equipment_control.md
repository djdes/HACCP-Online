# Journal `cold_equipment_control` — Журнал учета температурного режима холодильного оборудования

**Tier:** A (СанПиН-обязательный для всех общепит)
**СанПиН:** Прил. № 2 к СанПиН 2.3/2.4.3590-20
**Status:** draft

## Назначение

Ежедневный замер температуры в каждой единице холодильного/морозильного
оборудования. Подтверждает что цепь холода не нарушена. ХАССП —
критическая контрольная точка для скоропортящихся продуктов.

## Ритм

- **Frequency:** daily (минимум 1×/день, рекомендуется 2-3× для критич.
  оборудования — утром, в обед, вечером)
- **Per row:** ОДНО оборудование × ОДИН замер = ОДНА строка
- **Кто инициирует:** TasksFlow auto-fan-out утром, 1 задача на каждое
  включённое холодильное оборудование

## Роли

| Роль | Действие |
|------|----------|
| Filler | повар / уборщик / любой сотрудник смены |
| Verifier | шеф-повар или заведующая (опционально) |

## Pipeline (TF task)

1. **Шаг 1** «Сними показания термометра холодильника {название}» — поле
   number, валидация в диапазоне [-30, +30]
2. **Шаг 2** (условный) «t° вне диапазона {min}-{max} — что сделал?» —
   обязательный комментарий, photoMode: required (фото термометра как evidence)

photoMode: optional на шаге 1, required на шаге 2.

## Compliance rule

«Заполнен сегодня» = **все active equipment** (kind=fridge|freezer|chiller)
имеют запись на сегодня с непустым полем «Фактическая температура».

`DEEP_INSPECT_CODES` includes `cold_equipment_control` — мы смотрим внутрь
`entry.data.temperatures[equipmentId]` и сравниваем количество с
кол-вом активного оборудования.

## Edge cases

- **t° вне диапазона:** жёлтый/красный баннер, обязательное поле «причина
  и принятые меры». Auto-create CAPA-ticket если разница > 5°C от max.
- **Оборудование выключено / на ремонте:** строка не нужна. В UI можно
  пометить «Не работает сегодня» — попадает в audit-log как `noFunction`.
- **Морозильник vs холодильник:** разный диапазон. Подсказывается из
  `Equipment.maxTemp/minTemp` в форме.

## TasksFlow flow

- **Type:** N задач за день (1 на каждое active equipment kind=fridge|freezer)
- **rowKey:** `equipment::{equipmentId}`
- **Verifier:** опционально (управляется `Organization.taskFlowMode`)

## Срок хранения

3 мес. рекомендация ХАССП (логирование цепи холода).
