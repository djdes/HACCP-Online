# Journals `glass_items_list` + `glass_control` — Стекло и хрупкий пластик

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

`glass_items_list` — реестр всех стеклянных и хрупких пластиковых
изделий в производственной зоне (лампы, окна, посуда из стекла,
прозрачные крышки контейнеров). Отдельные позиции (не журнал-таблица).

`glass_control` — еженедельная проверка целостности этих позиций.
Защита от попадания осколков в продукт.

## Колонки `glass_items_list`

| # | Колонка | Тип |
|---|---------|-----|
| 1 | № | number (auto) |
| 2 | Расположение | text |
| 3 | Описание | text |
| 4 | Материал (стекло / поликарбонат / акрил) | select |
| 5 | Производитель | text |
| 6 | Дата установки | date |

## Колонки `glass_control`

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата проверки | date |
| 2 | Позиция (link to glass_items_list) | text |
| 3 | Состояние (Целое / Скол / Трещина / Разбито) | select |
| 4 | Принятые меры | text (если не «Целое») |
| 5 | Дата замены (если меняли) | date |
| 6 | Подпись | signature |
| 7 | Фото текущего состояния | photo |

## Ритм

- `glass_items_list`: event-driven (при добавлении нового изделия)
- `glass_control`: weekly (раз в неделю обходка)

## Pipeline (TF task)

Для weekly-проверки:
1. Шаг 1 — Обойди производство по списку позиций
2. Шаг 2 — Зафиксируй состояние каждой (photo: required)
3. Шаг 3 — Если разбито/скол → принять меры + CAPA

## TasksFlow flow

- **Type:** weekly recurring
- **rowKey:** `glass-check::{weekStart}`

## Compliance rule

Weekly-required (раз в 7 дней).

## Связи

При статусе «Разбито/Скол» → CAPA-ticket «изоляция зоны + поиск осколков
в продукции» + запись в `accident_journal`.
