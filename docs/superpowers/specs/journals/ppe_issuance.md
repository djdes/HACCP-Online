# Journal `ppe_issuance` — Журнал учета выдачи СИЗ (спецодежды)

**Tier:** C (ХАССП-рекомендуемый, обязателен по ТК РФ ст. 221)

## Назначение

Учёт выдачи спецодежды, перчаток, головных уборов сотрудникам. По нормам
СИЗ — 2 комплекта спецодежды на сотрудника, замена каждые 3-6 месяцев.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата выдачи | date |
| 2 | Сотрудник | text (auto) |
| 3 | Должность | text (auto) |
| 4 | Тип СИЗ (халат / шапочка / перчатки / фартук / обувь) | select |
| 5 | Размер | text |
| 6 | Количество, шт | number |
| 7 | Срок носки (мес) | number |
| 8 | Подпись получившего | signature |
| 9 | Подпись выдавшего | signature |
| 10 | Плановая дата следующей выдачи | date (auto) |

## Ритм

Event-driven (при выдаче). По плану 2-3 раза в год per-сотрудник.

## TasksFlow flow

- **Type:** event-driven при необходимости + reminder за 30 дней до
  следующей плановой выдачи
- **rowKey:** `ppe::{userId}::{timestamp}`

## Compliance rule

Сотрудники без СИЗ за период > N месяцев → жёлтый сигнал на дашборде.

## Sources
