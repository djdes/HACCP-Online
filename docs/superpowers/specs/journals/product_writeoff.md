# Journal `product_writeoff` — Акт забраковки

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Документальное оформление списания (брака) продукции: испорченной
сырья при приёмке, продуктов с истекшим сроком, готовых блюд после
бракеража с оценкой «неудовлетворительно». Связь с финансовым учётом.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата составления акта | date |
| 2 | № акта | text (auto) |
| 3 | Наименование продукта | text |
| 4 | Партия (batchKey) | text (link to traceability) |
| 5 | Количество, кг/л/шт | number |
| 6 | Стоимость, ₽ | number |
| 7 | Причина списания | select (просрочка / органолептика / поломка камеры / иное) |
| 8 | Способ утилизации | select (в мусор / на корм / возврат поставщику) |
| 9 | Подписи комиссии (1-3 чел) | signatures |
| 10 | Прикреплённое фото | photo (required) |

## Ритм

Event-driven.

## TasksFlow flow

- **Type:** event-driven (rolling); кнопка «+ списание»
- **rowKey:** `writeoff::{timestamp}::{batchKey}`

## Связи

- Ссылка на партию из **incoming_control** или **perishable_rejection**
- При причине «поломка камеры» → автоматическая запись в **accident_journal**

## Compliance rule

Не daily-rule.
