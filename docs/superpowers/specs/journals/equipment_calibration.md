# Journal `equipment_calibration` — График поверки средств измерений

**Tier:** C (ХАССП-рекомендуемый, обязателен для прибора в ККТ)
**Норматив:** ФЗ № 102-ФЗ «Об обеспечении единства измерений»

## Назначение

График поверки термометров, гигрометров, весов, тестеров фритюра.
Каждый прибор имеет дату последней поверки + следующей. После истечения
показания не могут считаться достоверными → нарушение ХАССП.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Прибор | text (auto из equipment) |
| 2 | Серийный номер | text |
| 3 | Производитель | text |
| 4 | Дата последней поверки | date |
| 5 | Результат поверки | select (Соответствует / Не соответствует) |
| 6 | Дата следующей поверки | date (auto = +12 мес обычно) |
| 7 | № сертификата / акта | text |
| 8 | Поверочная организация | text |
| 9 | Подпись ответственного | signature |

## Ритм

Per-прибор: событие поверки (1× в год для большинства приборов, 1× в 2 года
для весов в некоторых случаях). График — годовой.

## Pipeline (TF task)

1. Шаг 1 — Передай прибор в поверочную лабораторию
2. Шаг 2 — Зафиксируй № сертификата и дату следующей поверки
3. Шаг 3 — Прикрепи скан сертификата (photo: required)

## TasksFlow flow

- **Type:** event-driven (приближается дата → reminder); reminder за 30 / 7 / 1 день до истечения
- **rowKey:** `device::{equipmentId}::{calibrationDate}`

## Compliance rule

Просроченный прибор → жёлтый/красный сигнал. На дашборде «N приборов с
истекшей поверкой» — приоритетная плашка.
