# Journal `health_check` — Журнал здоровья

**Tier:** C (ХАССП-рекомендуемый, дополняет hygiene)
**СанПиН:** не прямо требуется (hygiene покрывает); ХАССП лучшая практика для крупных предприятий

## Назначение

Расширенная фиксация состояния здоровья сотрудников (медосмотры,
температура тела, плановые анализы) — выходит за рамки ежедневного
hygiene-журнала.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата | date |
| 2 | Сотрудник | text (auto) |
| 3 | Температура тела, °C | number |
| 4 | Жалобы (нет / есть) + текст | text |
| 5 | Решение (Допущен / Отстранён / На осмотр) | select |
| 6 | Подпись медработника / отв. лица | signature |

## Ритм

Daily, ОДИН сотрудник = ОДНА строка/день. Похоже на hygiene но с другим
fokус (физиология, не подпись об отсутствии инфекций).

## TasksFlow flow

Per-employee, rowKey `employee::{userId}`. Verifier — медработник или
заведующая.

## Compliance rule

`STRICT_COMPLETENESS_CODES` (как hygiene) — все active employees должны
быть отмечены.
