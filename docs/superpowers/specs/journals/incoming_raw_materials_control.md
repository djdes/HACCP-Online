# Journal `incoming_raw_materials_control` — Журнал входного контроля сырья, ингредиентов, упаковочных материалов

**Tier:** C (расширенная версия `incoming_control` для производств)

## Назначение

Расширенный журнал входного контроля для пищевых производств (хлебзавод,
кондитерский цех): дополнительно к `incoming_control` фиксируется
проверка упаковки, маркировки, соответствия ТТН.

## Отличия от `incoming_control`

`incoming_control` — базовый (готовая еда, скоропорт). Этот — для
сложного производства с несколькими видами сырья и упаковки.

## Колонки (дополнительно к incoming_control)

| # | Колонка | Тип |
|---|---------|-----|
| ... | (все колонки incoming_control) | ... |
| N+1 | Соответствие маркировки требованиям ТР ТС 022/2011 | boolean |
| N+2 | Состояние упаковки (целая / повреждена) | select |
| N+3 | Тип упаковочного материала | text |
| N+4 | № партии упаковки | text |
| N+5 | Сертификат соответствия упаковки | text/file |

## Ритм

Event-driven (как incoming_control).

## Status

Может быть **слит** с `incoming_control` через расширение полями
для production-mode орг (ТР ТС 022/2011 toggle).

## Sources

- ТР ТС 021/2011 ст. 8 (соблюдение целостности упаковки)
- ТР ТС 022/2011 (маркировка пищевой продукции)
