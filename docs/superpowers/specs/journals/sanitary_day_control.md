# Journal `sanitary_day_control` — Чек-лист проведения санитарного дня

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Ежемесячный санитарный день: глубокая уборка всех помещений,
дезинфекция, ревизия оборудования. Памятка-чек-лист с десятками
шагов: пол, стены, потолок, оборудование, вентиляция, мебель.

## Колонки (matrix-style: помещение × шаг)

| # | Шаг | Тип |
|---|-----|-----|
| 1 | Помещение | text (auto из rooms) |
| 2 | Очистка пола (соответствует / нет) | boolean |
| 3 | Очистка стен | boolean |
| 4 | Очистка потолка | boolean |
| 5 | Дезинфекция оборудования | boolean |
| 6 | Чистка вентиляции | boolean |
| 7 | Ревизия мебели | boolean |
| 8 | Уборка/замена ловушек грызунов | boolean |
| 9 | Подпись отв. лица | signature |

## Ритм

Monthly (раз в месяц, обычно последняя суббота).

## Pipeline (TF task)

Wizard по каждому помещению — большой чек-лист (8-15 шагов).

photoMode: required для ключевых шагов (вентиляция, оборудование).

## TasksFlow flow

- **Type:** monthly (per помещение)
- **rowKey:** `sanitary-day::{roomId}::{monthStart}`

## Compliance rule

Раз в месяц обязательно. > 35 дней без записи → красный сигнал.

## Связи

- При выявлении дефектов → CAPA-tickets per-помещение
- Связь с `equipment_maintenance` (обнаружили — добавили в график ППР)
