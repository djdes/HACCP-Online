# Journal `metal_impurity` — Журнал учета металлопримесей в сырье

**Tier:** C (ХАССП-рекомендуемый, обязателен где есть мукопросеиватель)

## Назначение

Контроль работы магнитного улавливателя в мукопросеивателе. По ХАССП —
ССКТ для мучных производств (хлеб, выпечка, кондитерка): даже мельчайшие
металлические частицы → угроза для потребителя.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата | date |
| 2 | Время проверки | time |
| 3 | Сырьё (мука / другое) | text |
| 4 | Партия | text (link batchKey) |
| 5 | Найдены металлопримеси? | boolean |
| 6 | Описание (при «Да») | text |
| 7 | Принятые меры | text |
| 8 | Подпись | signature |
| 9 | Фото магнита после очистки | photo |

## Ритм

Daily / per-смена (перед каждым использованием просеивателя).

## Pipeline (TF task)

1. Шаг 1 — Очисти магнит от налипшей муки
2. Шаг 2 — Осмотри (photo: required)
3. Шаг 3 — Найдены частицы? → если да → CAPA + изоляция партии

## TasksFlow flow

- **Type:** daily (per-смена)
- **rowKey:** `metal-check::{date}::{shift}`

## Compliance rule

Daily-required для орг с мукопросеивателем (kind=flour_sifter в equipment).

## Связи

- При находках → CAPA + блокировка соответствующего batchKey в traceability
