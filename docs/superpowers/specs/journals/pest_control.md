# Journal `pest_control` — Журнал дезинсекции, дератизации, дезинфекции (ДДД)

**Tier:** C (ХАССП-рекомендуемый)

## Назначение

Регистрация работ по борьбе с вредителями: грызуны, насекомые,
санитарная обработка помещений. Подтверждает что предприятие проводит
профилактические меры.

## Колонки

| # | Колонка | Тип |
|---|---------|-----|
| 1 | Дата | date |
| 2 | Тип работ (Дезинсекция / Дератизация / Дезинфекция) | select |
| 3 | Помещения / зоны | text |
| 4 | Используемый препарат / средство | text |
| 5 | Концентрация / дозировка | text |
| 6 | Подрядная организация | text |
| 7 | ФИО исполнителя | text |
| 8 | Договор / акт № | text |
| 9 | Подпись отв. лица | signature |
| 10 | Дата следующей плановой обработки | date (auto) |
| 11 | Прикреплённый акт | photo/file |

## Ритм

По графику: ежемесячно (дезинсекция/дератизация) + по требованию
(дезинфекция при ЧП).

## TasksFlow flow

- **Type:** event-driven (при выезде подрядчика) + reminder за 7 дней до плановой даты
- **rowKey:** `ddd::{type}::{date}`

## Compliance rule

Просрочка > 35 дней (для ежемесячной) → желтый сигнал. Acts uploaded — фиксированный документ.
