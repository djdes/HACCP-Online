# Journal `fryer_oil` — Журнал учета использования (замены) фритюрных жиров

**Tier:** A (СанПиН-обязательный при наличии фритюра)
**СанПиН:** п. 4.3 СанПиН 2.3/2.4.3590-20
**Status:** draft

## Назначение

Контроль качества фритюрного масла + фиксация замены при превышении норм
по полярным веществам (>25% — масло снимают). Защита от трансжиров и
канцерогенов. Срок хранения журнала **не менее 3 месяцев**.

## Колонки таблицы

| # | Колонка | Тип | Обяз. | Нормативный пин |
|---|---------|-----|-------|-----------------|
| 1 | Дата | date | да | п. 4.3 |
| 2 | Наименование фритюрницы / номер | text (auto) | да | п. 4.3 |
| 3 | Содержание вторичных продуктов окисления, % | number | да (при контроле) | п. 4.3 |
| 4 | Сделана замена? (Да/Нет) | boolean | да | п. 4.3 |
| 5 | Тип масла (марка) | text | при замене | best-practice |
| 6 | Объём заменённого масла, л | number | при замене | best-practice |
| 7 | Подпись ответственного | signature | да | п. 4.3 |
| 8 | Причина замены (плановая / превышение нормы / органолептика) | select | при замене | best-practice |

## Ритм

- **Frequency:** event-driven (при контроле качества + при замене).
  Контроль — обычно 1× в смену для активно используемого фритюра.
- **Per row:** ОДНО событие = ОДНА строка
- **Кто инициирует:** Power-staff (повар) ставит задачу при контроле
  или замене

## Pipeline (TF task)

1. **Шаг 1** «Замерь индекс окисления тестером (например, FOM)» — number, photo
2. **Шаг 2** (если >25%) «Слей и замени масло. Промой ванну» — confirm + required photo
3. **Шаг 3** «Запиши новое масло (марка, объём)» — fields

photoMode: required (тест-полоска / показания тестера).

## Compliance rule

Daily-check **не нужен** (event-driven). Для compliance считаем «настроен»
если у орги есть >0 фритюрниц И за последние 7 дней есть хотя бы одна
запись (т.е. контроль ведётся).

## Edge cases

- Если фритюра нет в орге — journal disabled (не показываем как
  обязательный, не штрафуем дашборд).

## TasksFlow flow

- **Type:** event-driven (rolling — кнопка «+ запись» в Mini App).
- **rowKey:** `fryer-event::{timestamp}` или `equipment::{fryerId}::{date}`

## Срок хранения

**3 месяца минимум** (СанПиН п. 4.3 явно).
