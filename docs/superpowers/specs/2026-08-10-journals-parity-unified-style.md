## Устройство эталона (наблюдения)

### Онбординг
- Пустой акк: каждый журнал — empty state «Документ ещё не создан» + «Создать документ».
- Создание документа блокируется, пока нет сотрудников: подсказка
  «Шаг 1: Добавить должность → Шаг 2: Добавить сотрудника».
- Сотрудники: страница «Сотрудники» = аккордеон компании с рубриками
  «Руководство» и «Сотрудники» → должности → люди. Плюс 4 таба графиков
  (выходные/отпуска/больничные/увольнения), которые влияют ТОЛЬКО на
  автозаполнение Гигиенического журнала (отметка «В»). Есть импорт выходных из iiko.

### Журнал уборки (эталон, разобран полностью)
- Создание документа: название + должность отв. за уборку → конкретный
  сотрудник + должность отв. за контроль → сотрудник (каскадные селекты,
  валидация «Поле не заполнено»).
- **Период документа = полмесяца** («Август с 1 по 15», дни 1–15 / 16–31).
- Документ: ХАССП-шапка (орг / СИСТЕМА ХАССП / СТР 1 ИЗ 1), кнопка
  «Добавить» → дропдаун: помещение / отв. за уборку / отв. за контроль.
- Добавление помещения: название, моющие средства (textarea), предметы
  текущей уборки (чипы-примеры + свой ввод + «добавить из файла» +
  «редактировать»), предметы генеральной уборки (в дополнение к текущей).
- **Прошедшие дни автоматически заполняются «/-/»** при создании строки.
- Клик по ячейке дня → диалог «Редактирование ячейки»: радио
  Текущая / Генеральная / Не проводилась + Сохранить.
- **Заполнение ячейки помещения автоматически ставит подпись С1 в строках
  ответственных за этот день.** Клик по ячейке ответственного → диалог смены
  сотрудника (подписавшего).
- «Настройки журнала» = переименование + смена ответственных (те же каскады).
- Тумблер «Автоматически заполнять журнал» на странице документа.
- Легенда: «/-/ Уборка не проводилась; Т — Текущая; Г — Генеральная …» +
  вторая таблица «Наименование помещения / Текущая уборка / Генеральная уборка».
- Экранный вид эталона — «бумажная» таблица с чёрными рамками (WeSetup
  скопировал её на экран 1:1; по решению владельца на экране WeSetup должен
  быть свой стиль, бумага — только в print/PDF).

### Осознанные отличия WeSetup от эталона (сохраняем)
- Заполнение ячейки: у эталона — диалог с радио; у WeSetup — тап-цикл
  Т → Г → «/» → пусто (меньше кликов, принцип UX №1) + rect-drag выделение.
- Печать: у эталона браузерная; у WeSetup — серверный PDF.
- WeSetup добавляет: TasksFlow-интеграцию (race-mode, фото, verify-flow),
  Mini App (П-3).
