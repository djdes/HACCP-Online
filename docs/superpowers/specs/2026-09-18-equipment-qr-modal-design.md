# Оборудование в журналах: правка из таблицы + QR в модалке + наклейки на A4

Дата: 2026-09-18. Задача: `.agent/tasks/equipment-qr-modal-2026-09/`.

## Проблема
В журнале холодильного оборудования название строки — просто текст; норму
можно поменять только через скрытую панель автозаполнения. QR для
заполнения с телефона есть лишь у строк, связанных со справочником
«Оборудование» (`sourceEquipmentId`); строки, добавленные в журнале, QR не
получают и не видны IoT/CAPA.

## Решение
1. **Клик по названию** (таблица и карточки) открывает существующий
   in-journal диалог строки. В диалоге — блок `QrFillPreview` с QR, нормой,
   сроком и кнопками «Плакат A4» / «Наклейка» (страница плакатов с
   `autoprint=1`).
2. **Сохранение** — `POST /api/journal-documents/[id]/cold-equipment`
   `{ action: "save_equipment", item }`: сервер обновляет запись
   справочника (или создаёт её: тип по норме, цех — первый/«Основной цех»),
   пишет `sourceEquipmentId`, сохраняет конфиг, синкает записи.
3. **Чекбоксы** → кнопка «QR-коды» в полосе выделения:
   `{ action: "ensure_equipment", itemIds }` связывает несвязанные строки,
   затем переход на `/settings/qr-posters?kind=equipment&layout=sheet&ids=…`.
4. **Страница плакатов** получает `layout=sheet` (много наклеек на A4) и
   `autoprint=1`. Старый `/settings/equipment/qr-sheet` → redirect.
5. **Климат**: название помещения кликабельно → карточка помещения; в
   секции «Климат» тот же `QrFillPreview kind="room"`.
6. `GET /api/qr-fill/[kind]/[id]` — единый источник QR для превью; общий
   билдер плаката `src/lib/qr-fill-poster.ts` используется и страницей плакатов.

Mini App рендерит те же клиенты (`/mini/documents/[id]`) — дублирования нет (П-3).

## Вне задачи
Журналы обслуживания/поверки/мойки оборудования; удаление записи
справочника при удалении строки; чекбоксы по помещениям в климате.
